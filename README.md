# 陕北红色文旅智能推荐系统

毕业设计项目，拟采用 Vue 3 + Spring Boot + MySQL + Neo4j，并结合检索增强生成和大语言模型。

## 当前进度

首个开发迭代：Spring Boot 提供景点筛选、主题推荐与参数校验；前端展示演示景点和推荐结果。当前数据为虚构演示数据，不可作为历史资料或论文实验结果。推荐只使用主题匹配，尚未接入知识图谱、大模型、用户系统或数据库。

## 环境

Java 21、Maven 3.9+、Node.js 20+。后端运行：

```bash
cd backend
mvn test
mvn spring-boot:run
```

前端运行（另一个终端）：

```bash
cd frontend
npm install
npm run dev
```

打开 Vite 输出的网址。前端开发服务器将 `/api` 请求代理至 `http://localhost:8080`。
